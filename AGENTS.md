# Project rules
- Embed the voice receptionist in a same-origin srcDoc iframe below the header; expand its viewport on interaction so the vendor's bottom-positioned closed-shadow widget remains usable at the top of the page.
- Keep weekly schedule entries in a browser-safe data module, referencing specialists by slug; resolve portraits and phone numbers from the shared specialist data to avoid duplicate contact details.
- Schedule pricing links target specialist anchors on the shared pricing page; prices remain defined only in the shared specialist data.
- Homepage service tiles use a browser-safe slug mapping and resolve specialists from shared data; single-person services link to profiles, while multi-person services open an accessible chooser so no practitioner is arbitrarily selected.
